# DOC_plus — шаблоны документации проекта

Набор основан на структуре документов Vildly-RAG-bot и CatPoop. Реестр открытых вопросов добавлен по примеру FableFox. Сведения, технологии и обязательства прежних проектов не перенесены.

## Как использовать

1. Скопируйте содержимое этой папки в `docs/` нового проекта.
2. Начните с vision, затем определите границы MVP и основные сценарии.
3. Заполните требования, план и архитектуру настолько, насколько они известны сейчас.
4. Замените поля `{{...}}`. Если решение пока неизвестно, добавьте вопрос в реестр.
5. Обновляйте документы после изменения требований и принятых решений. Удаляйте неприменимые разделы.

## Связь документов

Vision задаёт цель. План ограничивает объём работ. Сценарии уточняют требования. Архитектура описывает реализацию. Задачи ссылаются на требования, а итоги фиксируют результат.

Используйте стабильные ID: `BR-1` — функциональное требование, `NFR-1` — нефункциональное, `UF-1` — сценарий, `Q-1` — вопрос. Не меняйте номера уже используемых записей.

Для небольшого проекта достаточно начать с vision, требований и плана. Остальные документы заполняйте по необходимости. `issues.md` содержит текст для копирования: автоматические формы GitHub в этот набор не входят.
